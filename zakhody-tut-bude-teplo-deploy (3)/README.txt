«Заходь, тут буде тепло» — пакет для розміщення
================================================
Завантажте весь вміст архіву в одну папку на сервері: index.html у корені, поруч папка assets/.
Сторінку відкривайте через https:// (звук із файлу не працює при відкритті з диска).

Редагування в index.html:
- CONFIG — рядок 818: промокод (promoCode), термін (validUntil), умови (terms), посилання на категорію, UTM-мітки, товари.
  promoCode, validUntil, terms порожні — впишіть погоджені значення.
- COPY — рядок 877: увесь текст інтерфейсу.
- Масштаб кімнати на телефоні: константа ZOOM (1.3 = приблизно на 30% більше).

assets/video — ролики (.mp4 для Safari/iPhone, .webm для інших браузерів)
assets/audio — звук кімнати (.m4a, .webm; .wav — нестиснений для монтажу)
assets/img   — листочки, чайник, маски, перший кадр
assets/fonts — шрифт Fixel (MacPaw), ліцензія SIL OFL у OFL.txt
